# dartsapp

A full-featured darts scoring app with camera auto-detection support.

## Features

- 501 / 401 / 301 with double-out checkout suggestions
- vs Computer (Best of 3/5/7 — Beginner / Pub Player / World Class)
- Practice Finishing (40 / 100 / 170)
- Around the Clock Singles & Doubles
- **Camera Auto-Score** — background subtraction dart detection (requires HTTPS)
- Player profiles, stats & game history

---

## Deploy to GitHub Pages (free HTTPS)

> The camera feature requires HTTPS. GitHub Pages provides this for free.

### Step 1 — Create the repository

1. Go to [github.com](https://github.com) and sign in
2. Click **New repository**
3. Name it **dartsapp**
4. Set to **Public**
5. Click **Create repository**

### Step 2 — Upload the file

1. In your new repo, click **Add file → Upload files**
2. Drag and drop **index.html** from this folder
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages

1. Go to **Settings → Pages**
2. Under *Branch*, select **main** and folder **/ (root)**
3. Click **Save**

After ~60 seconds your app will be live at:

```
https://<your-github-username>.github.io/dartsapp/
```

## Using the Camera

1. Open the app on your phone/tablet over HTTPS (GitHub Pages URL above)
2. From the main menu tap **Camera Auto-Score**
3. Grant camera permission when prompted
4. Follow the **Calibrate Board** steps — tap Bull, T20, T6, T11, T3
5. Tap **Start Detection** — throw a dart, then tap **Confirm Score**

> **Tip:** Works best with good, even lighting on the dartboard.
